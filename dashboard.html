अपनी Strategy का Code पेस्ट करो

code अलग process में, restricted तरीके से चलता है — फिर वही backtest engine जो checkbox वाली strategies पर चलता है, वही यहाँ भी चलता है। result का फॉर्मेट दोनों जगह एक जैसा रहता है, ताकि तुलना करना आसान हो।

पैटर्न: def my_strategy(df): ... — df में open/high/low/close/volume columns हैं। अंत में एक boolean Series return करो (जहां True हो वहीं entry मानी जाएगी)।
Indicators: ind.compute("RSI", df, period=14) जैसे इस्तेमाल करो — 50 indicators पहले से उपलब्ध हैं (indicators.py देखो)।
इजाज़त: सिर्फ pandas (pd), numpy (np) और indicators (ind) इस्तेमाल हो सकते हैं — file/network/OS वाला कोड चलने से पहले ही रोक दिया जाता है।

System Self-Check

यह पूरा system चलाकर जांचता है — data files, सारे 50 indicators, backtest engine, और strategy sandbox। जो अपने-आप ठीक हो सकता है (missing folder, corrupt data file, टूटा हुआ indicator) वो कर देता है — बाकी पर लाल निशान लगाकर बताता है कि क्या करना है।

"Self-Check चलाओ" दबाओ — हर हिस्सा green/yellow/red मार्क के साथ दिखेगा।

रोज़ाना अपने-आप चलाने के लिए

Dashboard से manual चलाना काफ़ी ना लगे तो टर्मिनल पर python self_healing.py को cron/pm2 से हर 15 मिनट पर चला सकते हो — यह अपने-आप results/self_healing_log.json में history रखता है और कुछ लाल (FAIL) मिले तो exit code 1 देता है, जिस पर pm2/cron अलर्ट भेज सकता है। पूरी जानकारी SELF_HEALING_SETUP.md में है।
