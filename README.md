# Garuda Nexus

This repository contains multiple projects organized into folders:

## Projects

- **trading-bot/** - Trading bot application (API server, dashboard, indicators, strategies)
- **projecter/vault.html** - Vault app
- **projecter/garuda_power_tracker.html** - Garuda Power Tracker app

## Getting Started

Open `index.html` in the root to access a landing page linking to all three projects.
